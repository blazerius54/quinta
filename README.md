# Кварто-квинтовый круг

Интерактивная статическая страница для изучения кварто-квинтового круга. При наведении, фокусе или клике по сектору отображаются:

- состав выбранной тональности;
- диатонические трезвучия;
- септаккорды;
- параллельная тональность и знаки при ключе.

## Запуск

Откройте `index.html` в браузере.

Можно также запустить любой простой локальный сервер из корня проекта:

```sh
python3 -m http.server 8000
```

После этого страница будет доступна по адресу `http://localhost:8000`.
